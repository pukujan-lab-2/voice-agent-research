# Issue #31: The stack upgrade to 1.0.3 is refused, because the issue-log project file still names the repository's old owner

- State: closed (2026-10-31)
- Opened by Pukujan on 2026-10-31
- Original: https://github.com/Pukujan-lab/voice-agent-research/issues/31
- Labels: status:resolved

The automatic stack upgrade to agent-stack-train 1.0.3 stopped partway through for this repository. The other adopters upgraded normally.

## Symptoms

1. **Upgrade refused.** The upgrade-adopters run [41252932131](https://github.com/Pukujan/agent-stack-train/actions/runs/41252932131) reports `OIO install refused: project ontology identifies 'Pukujan/voice-agent-research', not target 'Pukujan-lab/voice-agent-research'`.

## Cause (confirmed)

The repository moved from the `Pukujan` account to the `Pukujan-lab` organization. The OIO (observational issue ops) project file `.oio/ontology/project.json` and `.oio/install-manifest.json` still record `project_id: Pukujan/voice-agent-research`. The installer refuses a target whose name does not match the recorded identity.

## Proposal

*(proposal)* Change `project_id` in both files to `Pukujan-lab/voice-agent-research`. Keep `namespace` as it is, so that existing concept IDs keep resolving. Then re-run the upgrade.
