Sends each live-demo call to Phoenix through Octo (Pukujan-lab/octo-database#268, Pukujan-lab/octo-database#342).

- `demo/live-site/tracing.ts`: OTLP/protobuf exporter to `<OCTO_BASE>/workspaces/<OCTO_WORKSPACE>/otel/v1/traces` with the workspace key (`OCTO_KEY`). Off without those env vars or with `OCTO_TRACES=off`.
- `api.ts`: traces understand, search (retriever with documents), judge and sentences. Adds `/api/trace` for widget spans (at most 10 per post, recent times only, attributes clipped).
- Widget: one call id per call, sent as `x-session-id` so a call is one Phoenix session. Spans for speech to text, text to speech, turn and call end.
- `widget/mask.ts`: masks SSN, date of birth and email in the browser and on the server before export.

Tested locally against live Octo: a typed call (serial, "yes", a manual question) showed up in Phoenix project `chatbots-factory` as call, turn, search, judge and sentences spans under one session.
