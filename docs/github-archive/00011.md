The widget still uses browser speech (`SpeechRecognition` / `speechSynthesis` in `demo/live-site/widget/sdk.ts`), which breaks decision 0002 (#4). In the owner's live test on 2026-10-31 it couldn't hear, its intro was long, it sounded robotic, it sent "can you hear me" to search, and it was slow.

**Done when**
- Voice goes through LiveKit Agents. Parakeet (or LFM3-Audio) listens and Pocket TTS speaks, both hosted by us.
- The mic is requested on Start, the intro is one short line, and the visitor can talk over it (barge-in).
- Small talk ("can you hear me", "hello") gets a short reply and never goes to search.
- Each turn's timing is logged per step, and an automated test with real audio passes.

In progress: LiveKit runs locally in Docker, and the Parakeet + Pocket TTS server is up on port 8799.
