## What changes

- `eval/propose.ts` reads the last week's flagged turns, groups them by rule, and files one issue per pattern (`Flagged turns: <pattern>`, with call, turn and evidence for each flag). If an issue for the pattern is open, it comments with only the new flags. It changes no code and moves no branch.
- A daily Claude desktop scheduled task, `copilot-flagged-turns` (06:40 local, runs while the app is open), runs `mine.ts`, `cases.ts` and `propose.ts` from a fresh checkout of `main`.
- Stops instead of filing when GitHub's list shows no open issues but the repository has some.
