A bad real turn, like the 2026-11-01 answer "I don't know" to "Can I file it from here?" when the search results held a passage saying yes, reaches the owner only as a complaint. Nothing looks at real calls.

## What changes

- `eval/mine.ts` reads the newest spans from the chatbots workspace (the nyc-map-agent workspace is refused by name), groups them into calls and turns, and flags suspect turns with seven plain-code rules (no model): judge dropped an answer that search found, one passage quoted for two different questions, a vague input answered by a quote, an invented offer, slow first sound or search, barge-ins, an unresolved call.
- Flags go to Octo's `flagged_turns` table (one row per call, turn and rule, so a re-run updates rows) and are printed. `--no-store` is a dry run. No local copy.
- 7 tests run the rules on a recording of the owner's call (`eval/tests/fixtures/`), needing no keys; `npm test` now runs them.
