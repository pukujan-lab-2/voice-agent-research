# PR #98: Block pull requests that bring back a fixed answer, and replay every case nightly

- State: open

- Original: https://github.com/Pukujan-lab/voice-agent-research/pull/98
- Branch `task/WCP-0024-replay-gate` into `main`, +1259 −22 in 14 files

CI never ran an answer, so a change could bring back a bad one unseen, and nothing recorded whether the live site got better or worse from day to day.

## What changes

- Every pull request now replays the `guarded` cases (fixed answers) on their recorded search and judge results, with no keys, and fails if one regresses (`npm run replay`, in `gates` and in `npm run check`). `open` cases (known bad) report but don't block.
- `.github/workflows/replay-live.yml` runs every night: it replays all cases against https://copilot.design-bakery.com (its own search, judge and desk model, so no secrets), posts the per-rule counts on the standing issue #97, and opens an issue for each rule whose failure count rose since the last post.
- `eval/cases/snapshot.json` is the cases exported from Octo (`node eval/replay.ts --export`). It is a test fixture like the recorded call, so CI needs no keys; Octo's table stays the store.
- Marks task WCP-0023 completed.
