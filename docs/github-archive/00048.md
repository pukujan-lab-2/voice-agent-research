# Issue #48: Questions about the assistant ("can I ask you about taxes?") get guide passages

- State: closed (2026-11-01)
- Opened by Pukujan on 2026-11-01
- Original: https://github.com/Pukujan-lab/voice-agent-research/issues/48
- Labels: status:resolved

### Summary

On a voice call to the tax demo, "can I ask you about taxes?" and "can I ask questions?" are sent to the IRS guide search as if they were tax questions. The search returns an unrelated passage (IRS Publication 970's "IRS.gov/Help" line) or "I couldn't find that in the tax guides". On 2026-10-31 the owner hit this repeatedly and said the assistant isn't answering smartly.

### Identity and Lineage

Leaf: this issue. Parent: none. Depends on: none. Related: #16 (the model-led desk, which is the full fix), #12.

### Acceptance Criteria

- "Can I ask you about taxes?", "can I ask questions?", "what can you help with?", "who are you?" and "are you a bot?" get a short answer about what the assistant does, then an invitation to ask, with no guide search.
- A real question that starts the same way ("can I ask about how to file an extension") still goes to the guides.
- `npm run check` passes.

### Boundaries and Next Action

In scope: the small-talk list in `demo/live-site/widget/sdk.ts`. Out of scope: wiring in the model-led desk (#16). Next action: add the patterns and the answer.

### Symptoms

1. **Meta question searched.** "Can I ask you about taxes?" opened IRS Publication 970 and highlighted an unrelated line.
2. **Fallback on repeat.** Asked again, it said "I couldn't find that in the tax guides I answer from".

### Hypotheses (unverified)

- **H1. The small-talk list has no entry for questions about the assistant.** Status: confirmed by reading `smallTalk()` in `sdk.ts`: anything not in the list goes to the guide search.

### Counter-signal

None.

### Honest Caveat

A phrase list only covers the phrasings it lists. The model-led desk (#16) is the real fix.

### Problems vs Gaps

Problem: questions about the assistant get guide passages. Gap: the live site still uses the rules desk instead of the model-led one (#16).

### Proposal *(proposal)*

Add a "help" kind to the small-talk list that says what the assistant does. It doesn't exist yet.
