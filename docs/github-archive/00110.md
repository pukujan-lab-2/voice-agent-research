# Issue #110: Let the model refine a search: a capped, fixed-size search_site tool

- State: open
- Opened by Pukujan on 2026-11-01
- Original: https://github.com/Pukujan-lab/voice-agent-research/issues/110

### Summary

One `answer_question` call does everything. A vague or two-part question cannot be refined: the model cannot see a few candidates, narrow, and ask again. This adds a `search_site` tool that returns a few cited passages with titles, capped per turn and trimmed to a fixed size, decided by code on top of the model's choice. Quote-only answers and the 'I don't know' path stay as they are.

### Identity and Lineage

Leaf: this issue. Parent: #107. Depends on: the filters child. Related: decision 0004 (Octo is the one store).

### Acceptance Criteria

- `search_site(query, section?, page_type?)` returns at most 4 results of at most 400 characters each, with title, url and passage id (tests).
- At most 3 `search_site` calls in a turn; the fourth is refused with a note (tests).
- An answer is still a quote from a cited passage; if nothing answers, the same 'I don't know' (tests, existing scenarios unchanged).
