# Issue #21: Move the checkout to PCM's project-folder layout so continuity validates

- State: open
- Opened by Pukujan on 2026-10-31
- Original: https://github.com/Pukujan-lab/voice-agent-research/issues/21
- Labels: infra

ACS needs the full PCM stack (#10). PCM's records are now in the repo (commit 4795367), but `continuity validate` fails on the folder layout alone. PCM's managed-worktrees mode wants the checkout at `<project>/main` with task worktrees under `<project>/worktrees/<TASK-ID>`. The Claude app keeps session worktrees inside the checkout (`.claude/worktrees/`).

`continuity worktree migrate --root ~/Documents/chatbots` would move the checkout, but it refuses while any worktree has unpushed or uncommitted work. Moving it also changes every running session's folder.

**Needs the owner's decision:** migrate, or keep the app's layout and accept that PCM validation only checks records.

**Done when** `continuity validate --root <checkout>` passes, or the decision to keep the app layout is recorded in docs/decisions.
