A voice call sat on "Connecting…" in silence until the agent joined, and forever when the agent was down.

## Problem and consequence

On 2026-10-31 the owner tapped "Start voice call" on the tax demo and waited more than a minute with no sound and no message. The agent worker was dead, but the caller had no way to know that.

## What changes

- While the call waits for the agent, the page plays a soft two-tone ringback (Web Audio, no file, no browser speech).
- The tone stops the moment the agent's audio arrives or its state moves past waiting.
- If no agent has joined after 20 seconds, the call switches to typing with "The voice line isn't answering right now, so let's carry on by typing."

## Before and after

| | Before | After |
|---|---|---|
| Waiting for the agent | Silence | Quiet ringing |
| Agent down | "Connecting…" forever | Typing after 20 s, with a message |
