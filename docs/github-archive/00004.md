# Issue #4: Decision 0002. Voice runs on LiveKit Agents

- State: closed (2026-10-31)
- Opened by Pukujan on 2026-10-31
- Original: https://github.com/Pukujan-lab/voice-agent-research/issues/4
- Labels: decision

Voice (and later phone calls) runs on LiveKit Agents (Apache-2.0), with Pipecat (BSD-2) as the fallback. Speech-to-text and text-to-speech are open models we host: LFM3-Audio or faster-whisper/Parakeet to listen, Pocket TTS (Kokoro as backup) to speak. Browser speech APIs are not allowed.

Full record: [docs/decisions/0002-voice-livekit-agents.md](https://github.com/Pukujan/voice-agent-research/blob/claude/strange-morse-7b3efa/docs/decisions/0002-voice-livekit-agents.md)
