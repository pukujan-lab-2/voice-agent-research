# PR #77: Add the LFM3-Audio voice stack and a tool-calling test for voice stacks

The owner chose LFM3-Audio for voice calls and asked where it is; there was no `lfm3-audio` stack to pick and no test showing whether any model here can call tools. This adds the stack and the test, with the first results. LFM3-Audio holds a call in English only, so that is all the stack lists.

## What changes

- `lfm3-audio` joins the voice stacks: one model, LFM3-Audio-2B on llama.cpp (the 4-bit file), hears each turn, speaks the reply and picks the desk's tools. It starts on the first call that picks it. Turns end on voice activity alone. It is listed in `/voice-lab` and pickable like the other stacks.
- `/api/desk` sends the desk's tool calls to LFM3-Audio when the call's stack is `lfm3-audio` (the page now sends the stack with each request). The code lock from decision 0011 is untouched and runs on the model's output.
- `demo/live-site/tests/voice-tools.ts` plays three scripted spoken calls through a stack's listener and model and counts two things separately: whether the model made the right tool call, and whether the form ended right.
- Decision 0013 records the choices; `docs/03-lfm3-omni-voice.md` is corrected with how the model runs on the 8 GB M1, its limits and the first tool-calling measurement.

## How to verify

`npm run check` passes (50 engine tests, 8 of 8 scenarios, ruff, tsc) and the app type-checks. To run the test: `cd demo/live-site && node --no-warnings tests/voice-tools.ts english-fast` (needs the speech server and the LFM3 text model) or `... lfm3-audio` (needs `speech/models/lfm3-audio`, see `speech/requirements.txt`). Full numbers and the live call are on [#71](https://github.com/Pukujan-lab/voice-agent-research/issues/71).

## Limits

One run each, a macOS voice instead of people, a synthetic caller with a mock engine in the live call, and the 4-bit file only. The Mac was already swapping, so memory is tight with other stacks loaded. A no-call turn once leaked the model's commentary into the reply. All are written up in decision 0013.
