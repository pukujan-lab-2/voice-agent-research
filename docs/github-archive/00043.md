# Issue #43: Voice call: ring while connecting, and stop waiting on a missing agent

- State: closed (2026-11-01)
- Opened by Pukujan on 2026-11-01
- Original: https://github.com/Pukujan-lab/voice-agent-research/issues/43
- Labels: status:resolved

### Summary

When a caller taps "Start voice call", the panel says "Connecting…" in silence until the voice agent joins, and if the agent never joins it stays that way for good. On 2026-10-31 the owner waited more than a minute with no sound and no message. The owner asked for a phone-call sound or a "please hold" while it connects.

### Identity and Lineage

Leaf: this issue. Parent: none. Depends on: none. Related: #11 (the voice call on LiveKit Agents).

### Acceptance Criteria

- While the call waits for the agent, the caller hears a soft ringing tone made in the page (no audio file, no browser speech).
- The ringing stops as soon as the agent joins and starts speaking.
- If no agent joins within 20 seconds, the call switches to typing with a message saying so, instead of staying on "Connecting…".
- `npm run check` passes.

### Boundaries and Next Action

In scope: `demo/live-site/widget/sdk.ts`. Out of scope: the agent process itself (it was restarted by hand on this Mac; see the caveat). Next action: add the ringback and the cutoff.

### Symptoms

1. **Silent wait.** Nothing plays between tapping the button and the agent's greeting.
2. **Endless "Connecting…".** With no agent running, the panel showed "Connecting… 1:00+" and never fell back to typing.

### Hypotheses (unverified)

- **H1. The agent never joined because its worker ran from a deleted folder.** Status: confirmed. The worker process ran `agent.py` from a removed worktree whose Python environment and models were gone, so each call's job could not start.

### Counter-signal

None.

### Honest Caveat

The ringing makes the wait audible and the cutoff ends a dead call, but neither makes the agent join any faster; a missing agent still means no voice.

### Problems vs Gaps

Problem: a dead call hangs with no feedback. Gap: there is no alert when the agent worker is down.

### Proposal *(proposal)*

Play a ringback tone from the page until the agent's audio arrives; after 20 seconds without an agent, carry on by typing. Neither exists yet.
