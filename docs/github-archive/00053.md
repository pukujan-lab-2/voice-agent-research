Decision 0003 says code owns every read-back and confirmation, but the owner now wants the model to lead and confirm according to how much an action matters.

## What changes

- New decision 0011 replaces 0003. The model leads the conversation, and each field or action gets a risk score from 1 to 100 that sets how it confirms. The bands run from "just do it" up to "a person approves".
- Rules on top of the bands: a mishearing adds 15 to the remaining steps, code locks everything from 56 up until a recorded yes, terms get a summary plus key clauses word for word, and skips or submits from 76 up are asked twice.
- The NYC map agent is recorded as low stakes, so it gets no confirmation steps.
- Each rule cites its source: Mycroft's confirmation guidelines, OpenAI's "A practical guide to building agents" (tool risk ratings, human intervention, layered guardrails), and LiveKit's prompting guide.
- 0003 is marked replaced and the index lists 0011.
