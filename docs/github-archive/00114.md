## What changes

- `.github/workflows/after-deploy.yml`: when `production` moves, wait 12 minutes for Komodo, check `/api/health`, replay every case against https://copilot.design-bakery.com (fails if a guarded case fails), and record the outcome in Phoenix as the eval span `deploy.replay` in session `deploy-<sha>` (`eval/after-deploy.ts`, through the site's `/api/score`, no keys).
- `demo/live-site/tests/voice-call.ts` takes `SITE_URL` to test a deployed site, and with `DEPLOY_SHA` records `deploy.voice-call` in the same session. `deploy/pro/voice-check.sh` runs it from the Pro (it needs macOS `say` and Chrome for Testing, so GitHub Actions can't); `update.sh` starts it after a deploy only if `deploy/.voice-check` exists.
