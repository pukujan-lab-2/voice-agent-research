# Feature checklist

What the largest general online retailers have in common, and what
Brambleway builds. Brambleway is fictional: it has its own name, palette, type, copy and layout, and no
real brand names appear anywhere in the app itself.

## Finding things

- [x] Search box in the header, on every page
- [x] Search suggestions (matching categories + product thumbnails) while typing
- [x] "Did you mean" spelling correction with a link back to the literal search
- [x] Relaxed fallback results when nothing matches every word
- [x] Browse by department (19 departments, each with categories)
- [x] Faceted filters: department, category, price buckets + range, rating, brand, colour, size
- [x] Filter counts on every option, removable chips, clear all
- [x] Sort: relevance, best sellers, price both ways, top rated, most reviews, newest, biggest discount
- [x] Numbered pagination, 24 per page
- [x] Empty state that suggests spelling, fewer filters, or departments
- [x] Filter state in the URL so a link or refresh shows the same list
- [x] Product comparison, up to 4 side by side, differences highlighted
- [x] Recently viewed products

## Products

- [x] Product page with image gallery and thumbnails
- [x] Variants: colour swatches and sizes, per-variant price and stock, out-of-stock options disabled
- [x] "Only N left" urgency and "In stock" / "Out of stock" states
- [x] Price, list price, percentage off, deal badge and deal end date
- [x] Star rating with review count
- [x] Rating histogram, each bar filters reviews
- [x] Sortable, paged customer reviews with variant attribution
- [x] Questions and answers
- [x] "About this item" bullets, description, full specifications table
- [x] Brand store links
- [x] Related / similar items
- [x] Quantity picker and add to cart
- [x] Add to wishlist
- [x] Delivery estimate

## Merchandising

- [x] Home page hero for the week's deals
- [x] Department tiles with imagery
- [x] Today's deals, top rated, new arrivals rows (sideways scroll on a phone)
- [x] Deal badges and struck-through list prices in every grid
- [x] Catalogue size in plain words
- [x] Wishlist

## Cart and checkout

- [x] Cart with quantity steppers, per-line stock errors, remove
- [x] Free-shipping progress bar
- [x] Shipping options with per-cart costs
- [x] Multi-step (clearly numbered) checkout on one page
- [x] Order review summary that updates with shipping and gift wrap
- [x] Estimated tax, gift wrap line, total
- [x] Demo payment step (no card fields, nothing charged)
- [x] Order confirmation

## After the sale

- [x] Order history with status trackers
- [x] Order detail with tracking timeline, carrier and tracking number
- [x] Cancel an order
- [x] Start a return (lines, quantity, reason, drop-off or mail-in)
- [x] Return history

## Service

- [x] Help centre with searchable articles grouped by section
- [x] Article pages with anchored sections, deep links and related articles
- [x] Account page for a guest shopper

## Not built (deliberately out of scope for this demo)

- [ ] Real accounts, sign-in and passwords (this store is a guest-only demo)
- [ ] Real payment, tax filing, or fulfilment
- [ ] Seller marketplace / third-party seller storefronts
- [ ] Loyalty programmes, registries, subscriptions
- [ ] Live chat support agents
- [ ] Personalised recommendations from browsing history beyond recently viewed
